# OpenCode IPC Contract Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add code generation (A), JSON Schema contract (B), and integration tests (C) to prevent cross-file inconsistencies between OpenCode TypeScript plugin and Rust TUI.

**Architecture:** Rust structs as canonical source of truth → `gen_contract.rs` binary generates JSON Schema + TypeScript types → committed files verified by `cargo test`. Plugin imports generated types. Runtime has zero validation.

**Tech Stack:** Rust (schemars for JSON Schema generation), TypeScript, serde

- [ ] **Step 2: Write the generator main function**

The binary reads canonical types from `chikuwa` library crate, generates JSON Schema via `schemars`, and outputs both files.

```rust
use std::fs;
use chikuwa::agent::state::AgentState;
use schemars::schema_for;
use schemars::schema::RootSchema;

fn main() {
    let args: Vec<String> = std::env::args().collect();
    match args.get(1).map(|s| s.as_str()) {
        Some("generate-contract") => generate_contract(),
        _ => eprintln!("Usage: cargo run -- generate-contract"),
    }
}

fn generate_contract() -> Result<(), Box<dyn std::error::Error>> {
    // Generate JSON Schema from canonical AgentState type
    let schema: RootSchema = schema_for!(AgentState);
    let schema_json = serde_json::to_string_pretty(&schema)?;
    fs::write("opencode-protocol.json", &schema_json)?;
    println!("Generated opencode-protocol.json");

    // Generate TypeScript types from the JSON Schema
    let ts_types = generate_typescript_types(&schema);
    fs::write("plugins/opencode-types.ts", &ts_types)?;
    println!("Generated plugins/opencode-types.ts");

    Ok(())
}
```

- [ ] **Step 3: Implement the TypeScript type generator**

Walk the JSON Schema definitions and produce TypeScript type definitions:

```rust
use schemars::schema::{RootSchema, Schema, SchemaObject, Type, SingleOrVec};

fn generate_typescript_types(schema: &RootSchema) -> String {
    let mut out = String::new();
    out.push_str("// Auto-generated by `cargo run -- generate-contract`. DO NOT EDIT.\n\n");

    // Process definitions in order: AgentStatus, ToolKey, ActiveTool, OpenCodeState, AgentData, AgentState
    let order = ["AgentStatus", "ToolKey", "ActiveTool", "OpenCodeState", "AgentState"];
    
    for name in &order {
        if let Some(def) = schema.definitions.get(*name) {
            match def {
                Schema::Object(obj) => {
                    if let Some(enum_values) = &obj.enum_values {
                        // Enum → TypeScript union type
                        let variants: Vec<&str> = enum_values.iter()
                            .filter_map(|v| v.as_str())
                            .collect();
                        out.push_str(&format!("export type {} = {};\n\n",
                            name,
                            variants.iter().map(|v| format!("\"{}\"", v)).collect::<Vec<_>>().join(" | ")));
                    } else if is_object_type(obj) {
                        // Object → TypeScript interface
                        out.push_str(&format!("export interface {} {{\n", name));
                        for (prop_name, prop_schema) in &obj.properties {
                            let required = obj.properties_required(prop_name);
                            let ts_type = type_ref_to_ts(prop_schema, &schema.definitions);
                            out.push_str(&format!("  {}{}: {};\n",
                                prop_name,
                                if required { "" } else { "?" },
                                ts_type));
                        }
                        out.push_str("}\n\n");
                    }
                }
                _ => {}
            }
        }
    }
    out
}
```

The `type_ref_to_ts` function converts schemars type refs to TS types:
- `string` → `string`
- `integer | number` → `number`  
- `boolean` → `boolean`
- `$ref` → resolve definition name
- `optional` → add `?` in interface, or `| undefined`
- `enum` → union of string literals

Create `tests/contract_test.rs`:

```rust
use chikuwa::agent::state::AgentState;
use schemars::schema_for;
use std::fs;

#[test]
fn test_contract_is_up_to_date() {
    // Generate expected schema from current types
    let expected = schema_for!(AgentState);
    let expected_json = serde_json::to_string_pretty(&expected).unwrap();
    
    // Read committed schema
    let actual = fs::read_to_string("opencode-protocol.json")
        .expect("opencode-protocol.json not found. Run: cargo run -- generate-contract");
    
    assert_eq!(
        serde_json::from_str::<serde_json::Value>(&expected_json).unwrap(),
        serde_json::from_str::<serde_json::Value>(&actual).unwrap(),
        "opencode-protocol.json is out of date. Run: cargo run -- generate-contract"
    );
}

#[test]
fn test_ts_types_up_to_date() {
    // Generate TS types from current types
    let schema = schema_for!(AgentState);
    let expected = generate_typescript_types(&schema);
    
    // Read committed TS types
    let actual = fs::read_to_string("plugins/opencode-types.ts")
        .expect("opencode-types.ts not found. Run: cargo run -- generate-contract");
    
    assert_eq!(expected, actual,
        "opencode-types.ts is out of date. Run: cargo run -- generate-contract");
}
```
